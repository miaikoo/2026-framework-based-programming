Studi kasus kedua praktikum adalah aplikasi Student Registration.

Praktikum 1 — Database StudentRegistrationDB

Rancangan Tabel

  • Programs — program studi. PK: ProgramId.
  • Students — data mahasiswa. PK: StudentId, FK: ProgramId → Programs.
  • Courses — mata kuliah. PK: CourseId, FK: ProgramId → Programs.
  • Registrations — pendaftaran mahasiswa ke mata kuliah. PK: RegistrationId, FK: StudentId → Students dan CourseId → Courses.

Relasi: Programs 1–N Students, Programs 1–N Courses, dan Students N–N Courses melalui tabel penghubung Registrations.

[Sisipkan gambar ERD: db-01-erd.png]

Constraint yang Dipakai

  • PRIMARY KEY + IDENTITY — ID unik yang bertambah otomatis.
  • FOREIGN KEY — mahasiswa hanya bisa memakai prodi yang ada; registrasi hanya untuk mahasiswa dan mata kuliah yang ada.
  • UNIQUE — NIM dan email tidak boleh ganda; kombinasi (StudentId, CourseId, Semester) mencegah daftar mata kuliah yang sama dua kali.
  • CHECK — Gender IN ('L','P'), Credits BETWEEN 1 AND 6, Status IN ('Aktif','Batal').
  • DEFAULT — RegisteredAt otomatis waktu sekarang, Status otomatis 'Aktif'.
  • ON DELETE CASCADE — jika mahasiswa dihapus, data pendaftarannya ikut terhapus.

Dibuat juga view vw_RegistrationDetails yang menggabungkan keempat tabel agar mudah dibaca aplikasi.

01_create_database.sql

/* =========================================================
   PRAKTIKUM 1 — Membuat database relasional StudentRegistrationDB
   Jalankan: sqlcmd -S localhost -E -C -i 01_create_database.sql
   ========================================================= */

-- Hapus database lama agar skrip bisa dijalankan ulang dari nol
IF DB_ID('StudentRegistrationDB') IS NOT NULL
BEGIN
    ALTER DATABASE StudentRegistrationDB SET SINGLE_USER WITH ROLLBACK IMMEDIATE;
    DROP DATABASE StudentRegistrationDB;
END
GO

CREATE DATABASE StudentRegistrationDB;
GO

USE StudentRegistrationDB;
GO

/* ---------- 1. Programs (Program Studi) ---------- */
CREATE TABLE Programs (
    ProgramId   INT IDENTITY(1,1) PRIMARY KEY,
    ProgramCode VARCHAR(10)   NOT NULL UNIQUE,
    ProgramName NVARCHAR(100) NOT NULL,
    Faculty     NVARCHAR(100) NOT NULL
);
GO

/* ---------- 2. Students (Mahasiswa) ---------- */
CREATE TABLE Students (
    StudentId  INT IDENTITY(1,1) PRIMARY KEY,
    Nim        VARCHAR(20)   NOT NULL UNIQUE,
    FullName   NVARCHAR(100) NOT NULL,
    Gender     CHAR(1)       NOT NULL CHECK (Gender IN ('L', 'P')),
    Email      NVARCHAR(100) NOT NULL UNIQUE,
    BirthDate  DATE          NOT NULL,
    EntryYear  SMALLINT      NOT NULL CHECK (EntryYear BETWEEN 2000 AND 2100),
    ProgramId  INT           NOT NULL,
    CONSTRAINT FK_Students_Programs
        FOREIGN KEY (ProgramId) REFERENCES Programs(ProgramId)
);
GO

/* ---------- 3. Courses (Mata Kuliah) ---------- */
CREATE TABLE Courses (
    CourseId   INT IDENTITY(1,1) PRIMARY KEY,
    CourseCode VARCHAR(10)   NOT NULL UNIQUE,
    CourseName NVARCHAR(100) NOT NULL,
    Credits    TINYINT       NOT NULL CHECK (Credits BETWEEN 1 AND 6),
    ProgramId  INT           NOT NULL,
    CONSTRAINT FK_Courses_Programs
        FOREIGN KEY (ProgramId) REFERENCES Programs(ProgramId)
);
GO

/* ---------- 4. Registrations (Pendaftaran mata kuliah) ----------
   Tabel penghubung many-to-many antara Students dan Courses */
CREATE TABLE Registrations (
    RegistrationId INT IDENTITY(1,1) PRIMARY KEY,
    StudentId      INT         NOT NULL,
    CourseId       INT         NOT NULL,
    Semester       VARCHAR(20) NOT NULL,          -- contoh: '2026/2027 Ganjil'
    RegisteredAt   DATETIME2   NOT NULL DEFAULT SYSDATETIME(),
    Status         VARCHAR(15) NOT NULL DEFAULT 'Aktif'
                   CHECK (Status IN ('Aktif', 'Batal')),
    CONSTRAINT FK_Registrations_Students
        FOREIGN KEY (StudentId) REFERENCES Students(StudentId) ON DELETE CASCADE,
    CONSTRAINT FK_Registrations_Courses
        FOREIGN KEY (CourseId) REFERENCES Courses(CourseId),
    -- Mahasiswa tidak boleh mendaftar mata kuliah yang sama dua kali di semester yang sama
    CONSTRAINT UQ_Registrations UNIQUE (StudentId, CourseId, Semester)
);
GO

/* ---------- 5. View gabungan untuk aplikasi ---------- */
CREATE VIEW vw_RegistrationDetails AS
SELECT  r.RegistrationId,
        s.Nim,
        s.FullName,
        p.ProgramName,
        c.CourseCode,
        c.CourseName,
        c.Credits,
        r.Semester,
        r.Status,
        r.RegisteredAt
FROM Registrations r
JOIN Students s ON s.StudentId = r.StudentId
JOIN Programs p ON p.ProgramId = s.ProgramId
JOIN Courses  c ON c.CourseId  = r.CourseId;
GO

PRINT 'Database StudentRegistrationDB dan 4 tabel berhasil dibuat.';
GO

03_queries.sql

/* =========================================================
   PRAKTIKUM 1 — Query pengujian relasi
   ========================================================= */
USE StudentRegistrationDB;
GO

-- 1. Daftar mahasiswa beserta nama program studinya (JOIN 2 tabel)
SELECT s.Nim, s.FullName, s.Gender, p.ProgramName, s.EntryYear
FROM Students s
JOIN Programs p ON p.ProgramId = s.ProgramId
ORDER BY s.Nim;
GO

-- 2. Detail pendaftaran mata kuliah (JOIN 4 tabel lewat view)
SELECT Nim, FullName, CourseCode, CourseName, Credits, Status
FROM vw_RegistrationDetails
ORDER BY Nim, CourseCode;
GO

-- 3. Total SKS aktif per mahasiswa (GROUP BY + SUM)
SELECT s.Nim, s.FullName, COUNT(*) AS JumlahMK, SUM(c.Credits) AS TotalSKS
FROM Registrations r
JOIN Students s ON s.StudentId = r.StudentId
JOIN Courses  c ON c.CourseId  = r.CourseId
WHERE r.Status = 'Aktif'
GROUP BY s.Nim, s.FullName
ORDER BY TotalSKS DESC, s.Nim;
GO

-- 4. Jumlah peserta per mata kuliah, termasuk yang belum ada peserta (LEFT JOIN)
SELECT c.CourseCode, c.CourseName,
       COUNT(r.RegistrationId) AS JumlahPeserta
FROM Courses c
LEFT JOIN Registrations r ON r.CourseId = c.CourseId AND r.Status = 'Aktif'
GROUP BY c.CourseCode, c.CourseName
ORDER BY JumlahPeserta DESC, c.CourseCode;
GO

-- 5. Uji constraint: mendaftar mata kuliah yang sama dua kali harus DITOLAK
BEGIN TRY
    INSERT INTO Registrations (StudentId, CourseId, Semester) VALUES (1, 1, '2026/2027 Ganjil');
END TRY
BEGIN CATCH
    PRINT 'Ditolak (sesuai harapan): ' + ERROR_MESSAGE();
END CATCH
GO

-- 6. Uji foreign key: ProgramId yang tidak ada harus DITOLAK
BEGIN TRY
    INSERT INTO Students (Nim, FullName, Gender, Email, BirthDate, EntryYear, ProgramId)
    VALUES ('9999999999', N'Uji FK', 'L', 'uji@x.id', '2006-01-01', 2024, 99);
END TRY
BEGIN CATCH
    PRINT 'Ditolak (sesuai harapan): ' + ERROR_MESSAGE();
END CATCH
GO

DataAccess.cs — kode ADO.NET

using System.Data;
using Microsoft.Data.SqlClient;

namespace StudentRegistrationApp
{
    // Semua pembacaan data dari StudentRegistrationDB menggunakan ADO.NET
    public static class DataAccess
    {
        // Ganti "localhost" jika nama server berbeda, misal "localhost\SQLEXPRESS"
        public const string ConnectionString =
            "Server=localhost;Database=StudentRegistrationDB;Trusted_Connection=True;TrustServerCertificate=True;";

        // Query untuk setiap tampilan. {0} = filter prodi, {1} = filter kata kunci
        private static readonly Dictionary<string, string> Queries = new Dictionary<string, string>
        {
            ["Mahasiswa"] = @"
                SELECT s.Nim AS [NIM], s.FullName AS [Nama],
                       CASE s.Gender WHEN 'L' THEN 'Laki-laki' ELSE 'Perempuan' END AS [Gender],
                       p.ProgramName AS [Program Studi], s.Email,
                       FORMAT(s.BirthDate, 'dd/MM/yyyy') AS [Tgl Lahir], s.EntryYear AS [Angkatan]
                FROM Students s
                JOIN Programs p ON p.ProgramId = s.ProgramId
                WHERE (@ProgramId = 0 OR s.ProgramId = @ProgramId)
                  AND (s.Nim LIKE @Cari OR s.FullName LIKE @Cari OR s.Email LIKE @Cari)
                ORDER BY s.Nim",

            ["Registrasi Mata Kuliah"] = @"
                SELECT v.Nim AS [NIM], v.FullName AS [Nama], v.ProgramName AS [Program Studi],
                       v.CourseCode AS [Kode MK], v.CourseName AS [Mata Kuliah], v.Credits AS [SKS],
                       v.Semester, v.Status, FORMAT(v.RegisteredAt, 'dd/MM/yyyy HH:mm') AS [Waktu Daftar]
                FROM vw_RegistrationDetails v
                JOIN Students s ON s.Nim = v.Nim
                WHERE (@ProgramId = 0 OR s.ProgramId = @ProgramId)
                  AND (v.Nim LIKE @Cari OR v.FullName LIKE @Cari OR v.CourseName LIKE @Cari OR v.CourseCode LIKE @Cari)
                ORDER BY v.Nim, v.CourseCode",

            ["Total SKS per Mahasiswa"] = @"
                SELECT s.Nim AS [NIM], s.FullName AS [Nama], p.ProgramName AS [Program Studi],
                       COUNT(r.RegistrationId) AS [Jumlah MK], ISNULL(SUM(c.Credits), 0) AS [Total SKS]
                FROM Students s
                JOIN Programs p ON p.ProgramId = s.ProgramId
                LEFT JOIN Registrations r ON r.StudentId = s.StudentId AND r.Status = 'Aktif'
                LEFT JOIN Courses c ON c.CourseId = r.CourseId
                WHERE (@ProgramId = 0 OR s.ProgramId = @ProgramId)
                  AND (s.Nim LIKE @Cari OR s.FullName LIKE @Cari)
                GROUP BY s.Nim, s.FullName, p.ProgramName
                ORDER BY [Total SKS] DESC, s.Nim",

            ["Mata Kuliah"] = @"
                SELECT c.CourseCode AS [Kode MK], c.CourseName AS [Mata Kuliah], c.Credits AS [SKS],
                       p.ProgramName AS [Program Studi], COUNT(r.RegistrationId) AS [Jumlah Peserta]
                FROM Courses c
                JOIN Programs p ON p.ProgramId = c.ProgramId
                LEFT JOIN Registrations r ON r.CourseId = c.CourseId AND r.Status = 'Aktif'
                WHERE (@ProgramId = 0 OR c.ProgramId = @ProgramId)
                  AND (c.CourseCode LIKE @Cari OR c.CourseName LIKE @Cari)
                GROUP BY c.CourseCode, c.CourseName, c.Credits, p.ProgramName
                ORDER BY c.CourseCode"
        };

        public static IEnumerable<string> DaftarTampilan => Queries.Keys;

        // Mengisi DataTable lewat SqlDataAdapter -> langsung bisa dipakai sebagai sumber DataGrid
        public static DataTable Ambil(string tampilan, int programId, string kataKunci)
        {
            var tabel = new DataTable();

            using (var conn = new SqlConnection(ConnectionString))
            using (var cmd = new SqlCommand(Queries[tampilan], conn))
            {
                cmd.Parameters.AddWithValue("@ProgramId", programId);
                cmd.Parameters.AddWithValue("@Cari", "%" + (kataKunci ?? "").Trim() + "%");

                using (var adapter = new SqlDataAdapter(cmd))
                {
                    adapter.Fill(tabel);   // Fill membuka & menutup koneksi otomatis
                }
            }

            return tabel;
        }

        // Daftar program studi untuk ComboBox filter (pakai SqlDataReader)
        public static List<KeyValuePair<int, string>> AmbilProgramStudi()
        {
            var hasil = new List<KeyValuePair<int, string>> { new KeyValuePair<int, string>(0, "Semua Program Studi") };

            using var conn = new SqlConnection(ConnectionString);
            using var cmd = new SqlCommand("SELECT ProgramId, ProgramName FROM Programs ORDER BY ProgramName", conn);
            conn.Open();

            using var reader = cmd.ExecuteReader();
            while (reader.Read())
            {
                hasil.Add(new KeyValuePair<int, string>(reader.GetInt32(0), reader.GetString(1)));
            }
            return hasil;
        }

        // Ringkasan angka untuk kartu di atas (ExecuteScalar per query)
        public static (int mahasiswa, int matkul, int registrasi, int prodi) AmbilRingkasan()
        {
            using var conn = new SqlConnection(ConnectionString);
            conn.Open();

            int Hitung(string sql) => (int)new SqlCommand(sql, conn).ExecuteScalar();

            return (Hitung("SELECT COUNT(*) FROM Students"),
                    Hitung("SELECT COUNT(*) FROM Courses"),
                    Hitung("SELECT COUNT(*) FROM Registrations WHERE Status = 'Aktif'"),
                    Hitung("SELECT COUNT(*) FROM Programs"));
        }
    }
}

MainWindow.xaml.cs

using System.Windows;
using System.Windows.Media;

namespace StudentRegistrationApp
{
    public partial class MainWindow : Window
    {
        private bool siap;   // mencegah query berjalan saat ComboBox masih diisi

        public MainWindow()
        {
            InitializeComponent();
        }

        private void Window_Loaded(object sender, RoutedEventArgs e)
        {
            try
            {
                cmbTampilan.ItemsSource = DataAccess.DaftarTampilan;
                cmbTampilan.SelectedIndex = 0;

                cmbProdi.ItemsSource = DataAccess.AmbilProgramStudi();
                cmbProdi.SelectedIndex = 0;

                siap = true;
                MuatData();
            }
            catch (Exception ex)
            {
                TampilkanError("Gagal terhubung ke database: " + ex.Message);
            }
        }

        // Dipanggil setiap kali tampilan, prodi, atau kata kunci berubah
        private void Filter_Changed(object sender, EventArgs e)
        {
            if (siap) MuatData();
        }

        private void BtnMuatUlang_Click(object sender, RoutedEventArgs e)
        {
            MuatData();
        }

        private void MuatData()
        {
            try
            {
                string tampilan = (string)cmbTampilan.SelectedItem;
                int programId = (int)(cmbProdi.SelectedValue ?? 0);

                var tabel = DataAccess.Ambil(tampilan, programId, txtCari.Text);
                dgData.ItemsSource = tabel.DefaultView;   // DataTable -> DataGrid

                var r = DataAccess.AmbilRingkasan();
                lblMahasiswa.Text = r.mahasiswa.ToString();
                lblProdi.Text = r.prodi.ToString();
                lblMatkul.Text = r.matkul.ToString();
                lblRegistrasi.Text = r.registrasi.ToString();

                lblStatus.Foreground = new SolidColorBrush(Color.FromRgb(0x64, 0x74, 0x8B));
                lblStatus.Text = $"{tabel.Rows.Count} baris ditampilkan · {tampilan} · dimuat {DateTime.Now:HH:mm:ss}";
            }
            catch (Exception ex)
            {
                TampilkanError("Gagal memuat data: " + ex.Message);
            }
        }

        private void TampilkanError(string pesan)
        {
            dgData.ItemsSource = null;
            lblStatus.Foreground = Brushes.Crimson;
            lblStatus.Text = pesan;
        }
    }
}

Penjelasan Kode

  • SqlDataAdapter.Fill(DataTable) — dipakai untuk mengisi DataGrid. DataTable langsung dijadikan ItemsSource lewat .DefaultView, dan kolom DataGrid dibuat otomatis dari hasil query.
  • SqlDataReader — dipakai untuk ComboBox program studi; membaca baris satu per satu, ringan untuk data kecil.
  • ExecuteScalar() — dipakai untuk kartu ringkasan yang hanya butuh satu angka (COUNT(*)).
  • Connection string memakai Trusted_Connection=True, artinya login dengan akun Windows tanpa password.
  • Query dalam Dictionary — nama tampilan dipetakan ke query SQL-nya, sehingga menambah tampilan baru cukup menambah satu entri.
  • Alias kolom seperti AS [Program Studi] langsung menjadi judul kolom DataGrid karena AutoGenerateColumns="True".
  • Parameter @ProgramId dan @Cari — filter dikirim sebagai parameter sehingga aman dari SQL Injection; @ProgramId = 0 berarti semua prodi.
  • Filter_Changed dipasang ke ComboBox dan TextBox sehingga setiap perubahan filter langsung menjalankan query ulang. Flag siap mencegah query berjalan saat ComboBox masih diisi.
  • Semua pembacaan dibungkus try/catch; jika database tidak bisa dihubungi, pesan merah muncul di status bar dan aplikasi tidak crash.

Kesimpulan

Praktikum 1 menghasilkan database StudentRegistrationDB dengan 4 tabel yang saling berelasi melalui primary key dan foreign key, dilengkapi constraint untuk menjaga konsistensi data. Praktikum 2 membuktikan bahwa aplikasi WPF dapat membaca data relasional tersebut menggunakan ADO.NET (SqlConnection, SqlCommand, SqlDataAdapter, SqlDataReader) dan menampilkannya pada DataGrid lengkap dengan filter dan pencarian.
