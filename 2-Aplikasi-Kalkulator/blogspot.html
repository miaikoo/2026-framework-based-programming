Tugas 2 PBKK — Aplikasi Kalkulator (C# Console)

📂 Source code lengkap: github.com/miaikoo/2026-framework-based-programming

Pada tugas ini dibuat aplikasi kalkulator berbasis console application C# dengan menu berwarna, validasi input, penanganan error (pembagian dengan nol dan akar bilangan negatif), serta riwayat perhitungan. Langkah instalasi .NET SDK, VS Code, dan C# Dev Kit sama seperti Tugas 1.

Fitur

  • 1 — Penjumlahan: a + b
  • 2 — Pengurangan: a - b
  • 3 — Perkalian: a × b
  • 4 — Pembagian: a ÷ b, menolak pembagian dengan nol
  • 5 — Pangkat: a ^ b memakai Math.Pow
  • 6 — Akar Kuadrat: √a memakai Math.Sqrt, menolak bilangan negatif
  • 7 — Riwayat: menampilkan semua perhitungan sebelumnya
  • 8 — Keluar: menutup program

1. Buat Proyek

Buka terminal VS Code dengan Ctrl+`, lalu jalankan:

dotnet new console -n Kalkulator
cd Kalkulator
code .

2. Ganti Isi Program.cs

Hapus seluruh isi Program.cs bawaan, ganti dengan kode berikut, lalu simpan (Ctrl+S):

using System;
using System.Collections.Generic;
using System.Globalization;

class Program
{
    // Riwayat perhitungan disimpan di memory (hilang saat program ditutup)
    static List<string> riwayat = new List<string>();

    static void Main()
    {
        // Agar ikon/emoji tampil dengan benar di konsol
        Console.OutputEncoding = System.Text.Encoding.UTF8;

        // Desimal selalu memakai titik (2.5), tidak tergantung bahasa Windows
        CultureInfo.CurrentCulture = CultureInfo.InvariantCulture;

        int pilihan;
        do
        {
            TampilkanMenu();
            Console.Write("\nPilihan: ");

            if (!int.TryParse(Console.ReadLine(), out pilihan))
            {
                pilihan = 0;
            }

            Console.WriteLine();
            switch (pilihan)
            {
                case 1: HitungDuaAngka("+", "PENJUMLAHAN", ConsoleColor.Green); break;
                case 2: HitungDuaAngka("-", "PENGURANGAN", ConsoleColor.Blue); break;
                case 3: HitungDuaAngka("×", "PERKALIAN", ConsoleColor.Yellow); break;
                case 4: HitungDuaAngka("÷", "PEMBAGIAN", ConsoleColor.Magenta); break;
                case 5: HitungDuaAngka("^", "PANGKAT", ConsoleColor.Cyan); break;
                case 6: HitungAkar(); break;
                case 7: TampilkanRiwayat(); break;
                case 8:
                    Console.ForegroundColor = ConsoleColor.Green;
                    Console.WriteLine("Terima kasih telah menggunakan kalkulator. 🧮");
                    Console.ResetColor();
                    break;
                default:
                    TulisWarna("Pilihan tidak tersedia!", ConsoleColor.Red);
                    break;
            }

            if (pilihan != 8)
            {
                Console.WriteLine("\nTekan ENTER untuk melanjutkan...");
                Console.ReadLine();
            }
        } while (pilihan != 8);
    }

    static void TampilkanMenu()
    {
        try { Console.Clear(); } catch { /* output dialihkan, abaikan */ }

        Console.ForegroundColor = ConsoleColor.Cyan;
        Console.WriteLine("==================================");
        Console.WriteLine("      🧮 APLIKASI KALKULATOR 🧮");
        Console.WriteLine("==================================");
        Console.ResetColor();

        TulisMenuItem(1, ConsoleColor.Green, "+", "Penjumlahan");
        TulisMenuItem(2, ConsoleColor.Blue, "-", "Pengurangan");
        TulisMenuItem(3, ConsoleColor.Yellow, "×", "Perkalian");
        TulisMenuItem(4, ConsoleColor.Magenta, "÷", "Pembagian");
        TulisMenuItem(5, ConsoleColor.Cyan, "^", "Pangkat");
        TulisMenuItem(6, ConsoleColor.DarkYellow, "√", "Akar Kuadrat");
        TulisMenuItem(7, ConsoleColor.White, "≡", "Riwayat Perhitungan");
        TulisMenuItem(8, ConsoleColor.DarkGray, ">", "Keluar");
    }

    // Menulis satu baris menu dengan "lencana" nomor berwarna
    static void TulisMenuItem(int nomor, ConsoleColor warnaLencana, string ikon, string teks)
    {
        Console.Write("   ");

        Console.BackgroundColor = warnaLencana;
        Console.ForegroundColor = ConsoleColor.Black;
        Console.Write(" " + nomor + " ");
        Console.ResetColor();

        Console.ForegroundColor = warnaLencana;
        Console.Write("  " + ikon);
        Console.ResetColor();

        Console.WriteLine("  " + teks);
    }

    // Membaca angka sampai input valid; menerima "2.5" maupun "2,5"
    static double BacaAngka(string label)
    {
        while (true)
        {
            Console.Write(label);
            string input = (Console.ReadLine() ?? "").Replace(',', '.');

            if (double.TryParse(input, out double angka))
            {
                return angka;
            }

            TulisWarna("Input harus berupa angka!", ConsoleColor.Red);
        }
    }

    // Operasi dengan dua angka: +, -, ×, ÷, ^
    static void HitungDuaAngka(string op, string judul, ConsoleColor warna)
    {
        TulisWarna("--- " + judul + " ---", warna);

        double a = BacaAngka("Angka pertama : ");
        double b = BacaAngka("Angka kedua   : ");

        double hasil;
        switch (op)
        {
            case "+": hasil = a + b; break;
            case "-": hasil = a - b; break;
            case "×": hasil = a * b; break;
            case "÷":
                if (b == 0)
                {
                    TulisWarna("Error: tidak bisa membagi dengan nol!", ConsoleColor.Red);
                    return;
                }
                hasil = a / b;
                break;
            case "^": hasil = Math.Pow(a, b); break;
            default: return;
        }

        TampilkanHasil(Format(a) + " " + op + " " + Format(b), hasil);
    }

    static void HitungAkar()
    {
        TulisWarna("--- AKAR KUADRAT ---", ConsoleColor.DarkYellow);

        double a = BacaAngka("Angka : ");

        if (a < 0)
        {
            TulisWarna("Error: akar dari bilangan negatif tidak terdefinisi!", ConsoleColor.Red);
            return;
        }

        TampilkanHasil("√" + Format(a), Math.Sqrt(a));
    }

    static void TampilkanHasil(string ekspresi, double hasil)
    {
        string baris = ekspresi + " = " + Format(hasil);
        riwayat.Add(baris);

        Console.Write("\nHasil : ");
        TulisWarna(baris, ConsoleColor.Green);
    }

    static void TampilkanRiwayat()
    {
        TulisWarna("--- RIWAYAT PERHITUNGAN ---", ConsoleColor.White);

        if (riwayat.Count == 0)
        {
            Console.WriteLine("Belum ada perhitungan.");
            return;
        }

        for (int i = 0; i < riwayat.Count; i++)
        {
            Console.WriteLine("{0,3}. {1}", i + 1, riwayat[i]);
        }
    }

    // Maksimal 4 angka desimal, tanpa nol berlebih: 2.5 bukan 2.5000
    static string Format(double angka)
    {
        return angka.ToString("0.####");
    }

    static void TulisWarna(string teks, ConsoleColor warna)
    {
        Console.ForegroundColor = warna;
        Console.WriteLine(teks);
        Console.ResetColor();
    }
}

3. Jalankan dan Uji Program

dotnet run
  • Penjumlahan 12 dan 8 → 12 + 8 = 20
  • Desimal 2,5 × 4 → 2.5 × 4 = 10 (koma maupun titik diterima)
  • Bagi nol 10 ÷ 0 → Error: tidak bisa membagi dengan nol!
  • Input huruf abc → Input harus berupa angka! lalu diminta ulang
  • Akar negatif -9 → Error: akar dari bilangan negatif tidak terdefinisi!
  • Riwayat (menu 7) → semua perhitungan yang berhasil tercantum bernomor

Contoh keluaran menu Riwayat:

--- RIWAYAT PERHITUNGAN ---
  1. 12 + 8 = 20
  2. 5 - 7.5 = -2.5
  3. 2.5 × 4 = 10
  4. 10 ÷ 3 = 3.3333
  5. 2 ^ 10 = 1024
  6. √144 = 12

Penjelasan Kode

  • List<string> riwayat — setiap hasil perhitungan disimpan sebagai teks agar bisa ditampilkan di menu Riwayat. Disimpan di RAM, jadi hilang saat program ditutup.
  • Main() — loop do...while dengan int.TryParse (anti-crash) dan switch. Lima operasi dua angka cukup memanggil satu method HitungDuaAngka() dengan parameter simbol, judul, dan warna berbeda.
  • BacaAngka() — loop while (true) yang terus meminta input sampai berupa angka. Koma diganti titik sehingga 2,5 dan 2.5 sama-sama diterima.
  • HitungDuaAngka() — switch pada simbol operator. Sebelum membagi dicek b == 0; jika ya, tampil pesan error dan return lebih awal (guard clause) sehingga tidak menghasilkan ∞. Pangkat memakai Math.Pow(a, b).
  • HitungAkar() — menolak bilangan negatif karena Math.Sqrt(-9) menghasilkan NaN.
  • TampilkanHasil() — mencetak hasil berwarna hijau sekaligus menambahkannya ke riwayat. Hanya perhitungan yang berhasil yang masuk riwayat.
  • Format() — ToString("0.####") menampilkan maksimal 4 desimal tanpa nol berlebih: 10 ÷ 3 = 3.3333.
  • TulisMenuItem() & TulisWarna() — helper pewarnaan dengan pola set warna → tulis → ResetColor() agar kode tidak berulang.
  • CultureInfo.InvariantCulture — desimal selalu memakai titik walau Windows berbahasa Indonesia.
