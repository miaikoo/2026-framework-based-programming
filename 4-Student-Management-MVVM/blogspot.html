Tugas 4 PBKK — Student Management System (WPF .NET 8 + MVVM + SQL Server)

📂 Source code lengkap: github.com/miaikoo/2026-framework-based-programming

Latihan ini berupa studi kasus pembuatan aplikasi Student Management System berbasis WPF (.NET 8) dengan pola arsitektur MVVM (Model-View-ViewModel). Aplikasi mengelola data mahasiswa (NIM, Nama, Jurusan, Gender, Email) dengan fitur CRUD, pencarian, dan statistik, yang seluruhnya terhubung ke SQL Server melalui ADO.NET.

Arsitektur MVVM

  • Model (Student) — hanya berisi data, tidak tahu UI maupun database.
  • View (MainWindow.xaml) — hanya tampilan. Tidak ada event Click; semua terhubung lewat {Binding} dan Command.
  • ViewModel (MainViewModel) — menyimpan isi form, daftar mahasiswa, statistik, serta logika validasi dan CRUD. Tidak menyentuh kontrol UI.
  • Repository (StudentRepository) — satu-satunya bagian yang berkomunikasi dengan SQL Server lewat ADO.NET.
View (XAML)  ──binding/command──►  ViewModel  ──panggil──►  Repository (ADO.NET)  ──►  SQL Server
             ◄──PropertyChanged───             ◄──Model───

Struktur Proyek

StudentManagement/
├── App.xaml
├── Models/       Student.cs, Statistik.cs
├── Data/         Database.cs, StudentRepository.cs
├── ViewModels/   BaseViewModel.cs, RelayCommand.cs, MainViewModel.cs
└── Views/        MainWindow.xaml, MainWindow.xaml.cs

Fitur

  • Create — tombol Tambah → INSERT
  • Read — tabel dimuat dari database saat aplikasi dibuka → SELECT
  • Update — klik baris, ubah data, tombol Ubah → UPDATE
  • Delete — klik baris, tombol Hapus, konfirmasi → DELETE
  • Pencarian — hasil langsung tersaring saat mengetik (NIM/Nama/Jurusan/Email) → LIKE
  • Statistik — total, jumlah laki-laki/perempuan, dan per jurusan → COUNT, SUM(CASE…), GROUP BY
  • Validasi — kolom wajib, NIM angka minimal 5 digit, format email, NIM tidak boleh ganda

1. Siapkan SQL Server

Instal SQL Server (Developer/Express) dan pastikan service-nya berjalan. Jika mati, buka PowerShell Run as Administrator:

Start-Service MSSQLSERVER

Aplikasi otomatis membuat database StudentDB dan tabel Students saat pertama dijalankan. Skrip SQL manualnya:

Data/Database.cs

using Microsoft.Data.SqlClient;

namespace StudentManagement.Data
{
    // Pengaturan koneksi + pembuatan database/tabel otomatis saat aplikasi pertama kali jalan
    public static class Database
    {
        // Ganti "localhost" jika nama server berbeda, misal "localhost\SQLEXPRESS" atau "(localdb)\MSSQLLocalDB"
        private const string Server = "localhost";
        private const string NamaDatabase = "StudentDB";

        public static string ConnectionString =>
            $"Server={Server};Database={NamaDatabase};Trusted_Connection=True;TrustServerCertificate=True;";

        private static string MasterConnectionString =>
            $"Server={Server};Database=master;Trusted_Connection=True;TrustServerCertificate=True;";

        public static void Inisialisasi()
        {
            // 1. Buat database jika belum ada
            using (var conn = new SqlConnection(MasterConnectionString))
            {
                conn.Open();
                var cmd = new SqlCommand(
                    $"IF DB_ID('{NamaDatabase}') IS NULL CREATE DATABASE [{NamaDatabase}];", conn);
                cmd.ExecuteNonQuery();
            }

            // 2. Buat tabel jika belum ada
            using (var conn = new SqlConnection(ConnectionString))
            {
                conn.Open();
                var cmd = new SqlCommand(@"
                    IF OBJECT_ID('dbo.Students', 'U') IS NULL
                    CREATE TABLE dbo.Students (
                        Id      INT IDENTITY(1,1) PRIMARY KEY,
                        Nim     VARCHAR(20)   NOT NULL UNIQUE,
                        Nama    NVARCHAR(100) NOT NULL,
                        Jurusan NVARCHAR(100) NOT NULL,
                        Gender  NVARCHAR(20)  NOT NULL,
                        Email   NVARCHAR(100) NOT NULL
                    );", conn);
                cmd.ExecuteNonQuery();
            }
        }
    }
}

Data/StudentRepository.cs

using Microsoft.Data.SqlClient;
using StudentManagement.Models;

namespace StudentManagement.Data
{
    // Semua akses database (ADO.NET) dikumpulkan di sini.
    // Selalu memakai parameter (@Nim, @Nama, ...) untuk mencegah SQL Injection.
    public class StudentRepository
    {
        public List<Student> GetAll()
        {
            return Query("SELECT Id, Nim, Nama, Jurusan, Gender, Email FROM Students ORDER BY Nim", null);
        }

        public List<Student> Search(string kataKunci)
        {
            return Query(@"SELECT Id, Nim, Nama, Jurusan, Gender, Email FROM Students
                           WHERE Nim LIKE @k OR Nama LIKE @k OR Jurusan LIKE @k OR Email LIKE @k
                           ORDER BY Nim",
                         cmd => cmd.Parameters.AddWithValue("@k", "%" + kataKunci + "%"));
        }

        public void Insert(Student s)
        {
            Execute(@"INSERT INTO Students (Nim, Nama, Jurusan, Gender, Email)
                      VALUES (@Nim, @Nama, @Jurusan, @Gender, @Email)", s);
        }

        public void Update(Student s)
        {
            Execute(@"UPDATE Students
                      SET Nim = @Nim, Nama = @Nama, Jurusan = @Jurusan, Gender = @Gender, Email = @Email
                      WHERE Id = @Id", s);
        }

        public void Delete(int id)
        {
            using var conn = new SqlConnection(Database.ConnectionString);
            using var cmd = new SqlCommand("DELETE FROM Students WHERE Id = @Id", conn);
            cmd.Parameters.AddWithValue("@Id", id);
            conn.Open();
            cmd.ExecuteNonQuery();
        }

        // Cek NIM ganda; abaikanId dipakai saat update agar data itu sendiri tidak dihitung
        public bool NimSudahAda(string nim, int abaikanId = 0)
        {
            using var conn = new SqlConnection(Database.ConnectionString);
            using var cmd = new SqlCommand("SELECT COUNT(*) FROM Students WHERE Nim = @Nim AND Id <> @Id", conn);
            cmd.Parameters.AddWithValue("@Nim", nim);
            cmd.Parameters.AddWithValue("@Id", abaikanId);
            conn.Open();
            return (int)cmd.ExecuteScalar() > 0;
        }

        public Statistik GetStatistik()
        {
            var stat = new Statistik();
            using var conn = new SqlConnection(Database.ConnectionString);
            conn.Open();

            // Total dan jumlah per gender dalam satu query
            using (var cmd = new SqlCommand(@"
                SELECT COUNT(*),
                       SUM(CASE WHEN Gender = 'Laki-laki' THEN 1 ELSE 0 END),
                       SUM(CASE WHEN Gender = 'Perempuan' THEN 1 ELSE 0 END)
                FROM Students", conn))
            using (var r = cmd.ExecuteReader())
            {
                if (r.Read())
                {
                    stat.Total = r.GetInt32(0);
                    stat.LakiLaki = r.IsDBNull(1) ? 0 : r.GetInt32(1);
                    stat.Perempuan = r.IsDBNull(2) ? 0 : r.GetInt32(2);
                }
            }

            // Jumlah per jurusan
            using (var cmd = new SqlCommand(
                "SELECT Jurusan, COUNT(*) FROM Students GROUP BY Jurusan ORDER BY COUNT(*) DESC, Jurusan", conn))
            using (var r = cmd.ExecuteReader())
            {
                while (r.Read())
                {
                    stat.PerJurusan.Add(new JumlahJurusan { Jurusan = r.GetString(0), Jumlah = r.GetInt32(1) });
                }
            }

            return stat;
        }

        // ===== Helper =====

        private List<Student> Query(string sql, Action<SqlCommand> isiParameter)
        {
            var hasil = new List<Student>();
            using var conn = new SqlConnection(Database.ConnectionString);
            using var cmd = new SqlCommand(sql, conn);
            isiParameter?.Invoke(cmd);
            conn.Open();

            using var reader = cmd.ExecuteReader();
            while (reader.Read())
            {
                hasil.Add(new Student
                {
                    Id = reader.GetInt32(0),
                    Nim = reader.GetString(1),
                    Nama = reader.GetString(2),
                    Jurusan = reader.GetString(3),
                    Gender = reader.GetString(4),
                    Email = reader.GetString(5)
                });
            }
            return hasil;
        }

        private void Execute(string sql, Student s)
        {
            using var conn = new SqlConnection(Database.ConnectionString);
            using var cmd = new SqlCommand(sql, conn);
            cmd.Parameters.AddWithValue("@Id", s.Id);
            cmd.Parameters.AddWithValue("@Nim", s.Nim);
            cmd.Parameters.AddWithValue("@Nama", s.Nama);
            cmd.Parameters.AddWithValue("@Jurusan", s.Jurusan);
            cmd.Parameters.AddWithValue("@Gender", s.Gender);
            cmd.Parameters.AddWithValue("@Email", s.Email);
            conn.Open();
            cmd.ExecuteNonQuery();
        }
    }
}

ViewModels/BaseViewModel.cs

using System.ComponentModel;
using System.Runtime.CompilerServices;

namespace StudentManagement.ViewModels
{
    // Dasar semua ViewModel: memberi tahu View setiap kali sebuah properti berubah
    public abstract class BaseViewModel : INotifyPropertyChanged
    {
        public event PropertyChangedEventHandler PropertyChanged;

        protected void OnPropertyChanged([CallerMemberName] string nama = null)
        {
            PropertyChanged?.Invoke(this, new PropertyChangedEventArgs(nama));
        }

        // Mengubah nilai field lalu memicu notifikasi hanya jika nilainya benar-benar berubah
        protected bool Set<T>(ref T field, T nilai, [CallerMemberName] string nama = null)
        {
            if (EqualityComparer<T>.Default.Equals(field, nilai)) return false;
            field = nilai;
            OnPropertyChanged(nama);
            return true;
        }
    }
}

ViewModels/RelayCommand.cs

using System.Windows.Input;

namespace StudentManagement.ViewModels
{
    // Menghubungkan tombol di View ke method di ViewModel tanpa event handler Click
    public class RelayCommand : ICommand
    {
        private readonly Action execute;
        private readonly Func<bool> canExecute;

        public RelayCommand(Action execute, Func<bool> canExecute = null)
        {
            this.execute = execute;
            this.canExecute = canExecute;
        }

        public bool CanExecute(object parameter) => canExecute == null || canExecute();

        public void Execute(object parameter) => execute();

        // WPF akan mengecek ulang CanExecute (aktif/nonaktif tombol) secara otomatis
        public event EventHandler CanExecuteChanged
        {
            add => CommandManager.RequerySuggested += value;
            remove => CommandManager.RequerySuggested -= value;
        }
    }
}

ViewModels/MainViewModel.cs

using System.Collections.ObjectModel;
using System.Text.RegularExpressions;
using System.Windows.Input;
using StudentManagement.Data;
using StudentManagement.Models;

namespace StudentManagement.ViewModels
{
    // VIEWMODEL: menyimpan state layar + logika, tanpa tahu apa pun tentang kontrol UI
    public class MainViewModel : BaseViewModel
    {
        private readonly StudentRepository repo = new StudentRepository();

        // ===== Data untuk View =====
        public ObservableCollection<Student> Students { get; } = new ObservableCollection<Student>();
        public ObservableCollection<JumlahJurusan> StatistikJurusan { get; } = new ObservableCollection<JumlahJurusan>();

        public List<string> DaftarJurusan { get; } = new List<string>
        {
            "Teknik Informatika", "Sistem Informasi", "Teknologi Informasi",
            "Rekayasa Perangkat Lunak", "Sains Data"
        };

        // ===== Field formulir (two-way binding) =====
        private string nim, nama, jurusan, email, cari, pesan;
        private bool isLaki = true, isPerempuan, pesanError;
        private int total, jumlahLaki, jumlahPerempuan;
        private Student selectedStudent;

        public string Nim { get => nim; set => Set(ref nim, value); }
        public string Nama { get => nama; set => Set(ref nama, value); }
        public string Jurusan { get => jurusan; set => Set(ref jurusan, value); }
        public string Email { get => email; set => Set(ref email, value); }
        public bool IsLaki { get => isLaki; set => Set(ref isLaki, value); }
        public bool IsPerempuan { get => isPerempuan; set => Set(ref isPerempuan, value); }

        public string Cari
        {
            get => cari;
            set { if (Set(ref cari, value)) MuatData(); }   // pencarian langsung saat mengetik
        }

        public string Pesan { get => pesan; set => Set(ref pesan, value); }
        public bool PesanError { get => pesanError; set => Set(ref pesanError, value); }

        public int Total { get => total; set => Set(ref total, value); }
        public int JumlahLaki { get => jumlahLaki; set => Set(ref jumlahLaki, value); }
        public int JumlahPerempuan { get => jumlahPerempuan; set => Set(ref jumlahPerempuan, value); }

        // Saat baris tabel dipilih, isi formulir dengan datanya
        public Student SelectedStudent
        {
            get => selectedStudent;
            set
            {
                if (!Set(ref selectedStudent, value) || value == null) return;
                Nim = value.Nim;
                Nama = value.Nama;
                Jurusan = value.Jurusan;
                Email = value.Email;
                IsLaki = value.Gender == "Laki-laki";
                IsPerempuan = !IsLaki;
                Pesan = "";
            }
        }

        // ===== Command untuk tombol =====
        public ICommand TambahCommand { get; }
        public ICommand UbahCommand { get; }
        public ICommand HapusCommand { get; }
        public ICommand BersihkanCommand { get; }

        // Diisi oleh View untuk menampilkan dialog konfirmasi (ViewModel tidak memanggil MessageBox langsung)
        public Func<string, bool> Konfirmasi { get; set; } = _ => true;

        public MainViewModel()
        {
            TambahCommand = new RelayCommand(Tambah);
            UbahCommand = new RelayCommand(Ubah, () => SelectedStudent != null);
            HapusCommand = new RelayCommand(Hapus, () => SelectedStudent != null);
            BersihkanCommand = new RelayCommand(Bersihkan);

            try
            {
                Database.Inisialisasi();
                MuatData();
            }
            catch (Exception ex)
            {
                TampilkanPesan("Gagal terhubung ke database: " + ex.Message, true);
            }
        }

        // ===== CRUD =====

        private void Tambah()
        {
            if (!Validasi(0)) return;
            Jalankan(() => repo.Insert(BuatStudent(0)), "Data " + Nama.Trim() + " berhasil ditambahkan.");
        }

        private void Ubah()
        {
            if (!Validasi(SelectedStudent.Id)) return;
            Jalankan(() => repo.Update(BuatStudent(SelectedStudent.Id)), "Data " + Nama.Trim() + " berhasil diperbarui.");
        }

        private void Hapus()
        {
            var s = SelectedStudent;
            if (!Konfirmasi("Hapus data " + s.Nama + " (" + s.Nim + ")?")) return;
            Jalankan(() => repo.Delete(s.Id), "Data " + s.Nama + " berhasil dihapus.");
        }

        private void Bersihkan()
        {
            KosongkanForm();
            Pesan = "";
        }

        // Menjalankan operasi database, lalu memuat ulang tabel & statistik
        private void Jalankan(Action aksi, string pesanSukses)
        {
            try
            {
                aksi();
                KosongkanForm();
                MuatData();
                TampilkanPesan(pesanSukses, false);
            }
            catch (Exception ex)
            {
                TampilkanPesan("Terjadi kesalahan database: " + ex.Message, true);
            }
        }

        private void MuatData()
        {
            try
            {
                var data = string.IsNullOrWhiteSpace(Cari) ? repo.GetAll() : repo.Search(Cari.Trim());
                Students.Clear();
                foreach (var s in data) Students.Add(s);

                var stat = repo.GetStatistik();
                Total = stat.Total;
                JumlahLaki = stat.LakiLaki;
                JumlahPerempuan = stat.Perempuan;
                StatistikJurusan.Clear();
                foreach (var j in stat.PerJurusan) StatistikJurusan.Add(j);
            }
            catch (Exception ex)
            {
                TampilkanPesan("Gagal memuat data: " + ex.Message, true);
            }
        }

        // ===== Helper =====

        private bool Validasi(int idSaatIni)
        {
            if (string.IsNullOrWhiteSpace(Nim) || string.IsNullOrWhiteSpace(Nama) ||
                string.IsNullOrWhiteSpace(Jurusan) || string.IsNullOrWhiteSpace(Email))
                return Gagal("Semua kolom wajib diisi!");

            if (!Regex.IsMatch(Nim.Trim(), @"^\d{5,20}$"))
                return Gagal("NIM harus berupa angka (minimal 5 digit).");

            if (!Regex.IsMatch(Email.Trim(), @"^[^@\s]+@[^@\s]+\.[^@\s]+$"))
                return Gagal("Format email tidak valid.");

            try
            {
                if (repo.NimSudahAda(Nim.Trim(), idSaatIni))
                    return Gagal("NIM " + Nim.Trim() + " sudah terdaftar.");
            }
            catch (Exception ex)
            {
                return Gagal("Gagal mengecek NIM: " + ex.Message);
            }

            return true;
        }

        private bool Gagal(string pesan)
        {
            TampilkanPesan(pesan, true);
            return false;
        }

        private Student BuatStudent(int id) => new Student
        {
            Id = id,
            Nim = Nim.Trim(),
            Nama = Nama.Trim(),
            Jurusan = Jurusan,
            Gender = IsLaki ? "Laki-laki" : "Perempuan",
            Email = Email.Trim()
        };

        private void KosongkanForm()
        {
            Nim = Nama = Email = "";
            Jurusan = null;
            IsLaki = true;
            IsPerempuan = false;
            SelectedStudent = null;
        }

        private void TampilkanPesan(string teks, bool error)
        {
            PesanError = error;
            Pesan = teks;
        }
    }
}

Penjelasan Kode

Data (ADO.NET)

  • Database.Inisialisasi() — konek ke master, membuat database jika belum ada, lalu membuat tabel jika belum ada, sehingga aplikasi bisa langsung dipakai.
  • Pola ADO.NET — SqlConnection → SqlCommand → ExecuteReader() untuk SELECT, ExecuteNonQuery() untuk INSERT/UPDATE/DELETE, ExecuteScalar() untuk satu nilai. Semua dibungkus using agar koneksi otomatis ditutup.
  • Parameter @Nim, @Nama, … — input tidak pernah digabung langsung ke string SQL, sehingga aman dari SQL Injection.
  • NimSudahAda(nim, abaikanId) — WHERE Nim = @Nim AND Id <> @Id; saat update, data itu sendiri tidak dianggap duplikat.
  • GetStatistik() — COUNT(*) + SUM(CASE WHEN Gender = ...) untuk total dan gender, GROUP BY Jurusan untuk per jurusan.

ViewModel

  • BaseViewModel — implementasi INotifyPropertyChanged; Set(ref field, value) mengubah nilai lalu memberi tahu View.
  • RelayCommand — implementasi ICommand. Tombol memakai Command="{Binding TambahCommand}", bukan event Click. canExecute membuat tombol Ubah/Hapus otomatis nonaktif jika belum ada baris dipilih.
  • MainViewModel — properti form terikat two-way ke input; Students dan StatistikJurusan berupa ObservableCollection; setter SelectedStudent mengisi form; setter Cari langsung memuat ulang data; Jalankan() menjalankan operasi DB lalu memuat ulang tabel dan statistik, dengan error ditangkap try/catch.
  • Konfirmasi — Func<string, bool> yang diisi oleh View, sehingga ViewModel tidak memanggil MessageBox langsung dan tetap bebas dari kode UI.

View

  • <Window.DataContext><vm:MainViewModel/></Window.DataContext> menghubungkan View ke ViewModel.
  • UpdateSourceTrigger=PropertyChanged mengirim nilai ke ViewModel setiap ketikan.
  • DataTrigger mengubah warna pesan: merah saat error, hijau saat sukses.
  • MainWindow.xaml.cs hanya berisi InitializeComponent() dan penyedia dialog konfirmasi.
