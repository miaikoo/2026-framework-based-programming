Tugas 9 PBKK — ShopEase Authentication System dengan CodeIgniter 3

📂 Source code lengkap: github.com/miaikoo/2026-framework-based-programming

Pada tugas ini saya menambahkan sistem akun ke toko online ShopEase dari tugas sebelumnya: registrasi, login, logout, dan pembatasan halaman berdasarkan peran customer, operator, dan admin. Aplikasi dibuat dengan CodeIgniter 3.1.13 dan MySQL di XAMPP. Data pengguna disimpan lewat Model, password di-hash, identitas dijaga dengan Session, dan sebuah hook memeriksa peran sebelum Controller menampilkan View.

[Sisipkan gambar: s9-01-login.png]

Fitur

  • Inti: registrasi dengan validasi per kolom, login, logout (POST + CSRF), password di-hash, ID sesi diganti setelah login.
  • Hak akses: peta akses di config/akses.php + hook Penjaga_akses sebagai pengganti Filter CI4. Tamu dialihkan ke login, peran yang tidak berhak mendapat halaman 403.
  • Peran: customer → /akun; operator → /operator (stok menipis & data pelanggan); admin → /admin dan /admin/pengguna (ubah peran, hapus akun).
  • Ingat saya: token selector + validator di tabel remember_tokens, hanya hash yang disimpan, token dirotasi setiap dipakai dan dicabut saat password diganti.
  • Batas percobaan: 5 kali gagal dalam 15 menit (email + IP sama) mengunci login 5 menit; dicatat di tabel login_attempts yang juga menjadi log aktivitas admin.
  • Lainnya: kembali ke halaman tujuan setelah login, ganti password, lupakan semua perangkat, perubahan peran berlaku tanpa login ulang, tampilan HP.

Cara Menjalankan

  1. Start Apache dan MySQL di XAMPP.
  2. Import database/db_shopease.sql lewat phpMyAdmin.
  3. Buka http://localhost/pbkk9/shopease/. Akun contoh: admin@shopease.test, operator@shopease.test, raka@shopease.test, password shopease123.

Langkah 1. Database db_shopease

-- =========================================================
-- Tugas 9 - ShopEase Authentication System (CodeIgniter 3)
-- Database: db_shopease
-- Import lewat phpMyAdmin (tab Import) atau:  mysql -u root < db_shopease.sql
-- Password semua akun contoh: shopease123
-- =========================================================
DROP DATABASE IF EXISTS db_shopease;
CREATE DATABASE db_shopease CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE db_shopease;

-- Pengguna. Peran: customer (pembeli), operator (staf toko), admin (pemilik/pengelola).
CREATE TABLE users (
    id_user        INT AUTO_INCREMENT PRIMARY KEY,
    name           VARCHAR(100) NOT NULL,
    email          VARCHAR(100) NOT NULL UNIQUE,
    password       VARCHAR(255) NOT NULL,                 -- hasil password_hash()
    role           ENUM('customer','admin','operator') NOT NULL DEFAULT 'customer',
    phone          VARCHAR(20),
    address        TEXT,
    last_login_at  DATETIME NULL,
    created_at     DATETIME NULL,
    updated_at     DATETIME NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- Setiap percobaan login dicatat: dipakai untuk membatasi percobaan gagal
-- dan ditampilkan sebagai log aktivitas di dashboard admin.
CREATE TABLE login_attempts (
    id          INT AUTO_INCREMENT PRIMARY KEY,
    email       VARCHAR(100) NOT NULL,
    ip_address  VARCHAR(45)  NOT NULL,
    berhasil    TINYINT(1)   NOT NULL,
    user_agent  VARCHAR(255) NULL,
    created_at  DATETIME     NOT NULL,
    INDEX idx_email_ip_waktu (email, ip_address, created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- Token "Ingat saya" (pola selector + validator).
-- Cookie berisi selector:validator; yang disimpan di database hanya hash validator.
CREATE TABLE remember_tokens (
    id              INT AUTO_INCREMENT PRIMARY KEY,
    id_user         INT          NOT NULL,
    selector        CHAR(24)     NOT NULL UNIQUE,
    validator_hash  CHAR(64)     NOT NULL,
    expires_at      DATETIME     NOT NULL,
    created_at      DATETIME     NOT NULL,
    CONSTRAINT fk_token_user FOREIGN KEY (id_user) REFERENCES users(id_user) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

Langkah 2. Konfigurasi

  • config/database.php: database db_shopease, user root, charset utf8mb4.
  • config/autoload.php: database, session, form_validation, dan library 'autentikasi' => 'auth'. Nama class library dibedakan dari controller Auth agar tidak bentrok.
  • config/config.php: enable_hooks = TRUE, csrf_protection = TRUE, cookie_httponly = TRUE.

config/akses.php — peta hak akses

<?php
defined('BASEPATH') OR exit('No direct script access allowed');

/*
| -------------------------------------------------------------------
| Peta hak akses ShopEase
| -------------------------------------------------------------------
| CodeIgniter 3 tidak punya "Filter" seperti CI4. Sebagai gantinya, hook
| Penjaga_akses (application/hooks/Penjaga_akses.php) membaca peta ini
| SEBELUM method controller dijalankan.
|
| Kunci  = awalan URI (segmen pertama setelah base URL).
| Nilai  = 'login'                      -> semua peran yang sudah login
|          array('admin', 'operator')   -> hanya peran tersebut
|
| URI yang tidak tercantum bersifat publik (landing page, katalog, keranjang).
*/
$config['akses'] = array(
    'akun'     => 'login',
    'operator' => array('operator', 'admin'),   // admin juga boleh membuka halaman operator
    'admin'    => array('admin'),
);

/*
| Halaman khusus tamu. Pengguna yang sudah login diarahkan ke beranda perannya.
*/
$config['khusus_tamu'] = array('login', 'register');

/*
| Halaman awal setiap peran setelah login.
*/
$config['beranda_peran'] = array(
    'admin'    => 'admin',
    'operator' => 'operator',
    'customer' => 'akun',
);

/*
| Pembatasan percobaan login: BATAS kali gagal dalam JENDELA menit untuk
| email + IP yang sama akan mengunci login selama KUNCI menit.
*/
$config['login_batas_gagal']   = 5;
$config['login_jendela_menit'] = 15;
$config['login_kunci_menit']   = 5;

/*
| Umur cookie "Ingat saya" (hari).
*/
$config['ingat_saya_hari'] = 30;

Langkah 3. Model

models/User_model.php

<?php
defined('BASEPATH') OR exit('No direct script access allowed');

class User_model extends CI_Model
{
    private $table = 'users';

    /** Kolom yang aman ditampilkan (tanpa password) */
    const KOLOM_PUBLIK = 'id_user, name, email, role, phone, address, last_login_at, created_at, updated_at';

    const PERAN = array('customer', 'operator', 'admin');

    public function cari($id)
    {
        return $this->db->get_where($this->table, array('id_user' => (int) $id))->row();
    }

    public function cari_by_email($email)
    {
        return $this->db->get_where($this->table, array('email' => strtolower(trim($email))))->row();
    }

    /** Akun baru dari form registrasi. Peran selalu customer. */
    public function daftar(array $data)
    {
        $now = date('Y-m-d H:i:s');
        $this->db->insert($this->table, array(
            'name'       => $data['name'],
            'email'      => strtolower($data['email']),
            'password'   => password_hash($data['password'], PASSWORD_DEFAULT),
            'role'       => 'customer',
            'phone'      => $data['phone'] !== '' ? $data['phone'] : NULL,
            'address'    => $data['address'] !== '' ? $data['address'] : NULL,
            'created_at' => $now,
            'updated_at' => $now,
        ));
        return $this->db->insert_id();
    }

    public function ubah_profil($id, array $data)
    {
        $data['updated_at'] = date('Y-m-d H:i:s');
        return $this->db->update($this->table, $data, array('id_user' => (int) $id));
    }

    public function ganti_password($id, $password_baru)
    {
        return $this->ubah_profil($id, array('password' => password_hash($password_baru, PASSWORD_DEFAULT)));
    }

    public function catat_login($id)
    {
        $this->db->update($this->table, array('last_login_at' => date('Y-m-d H:i:s')), array('id_user' => (int) $id));
    }

    /** Daftar pengguna untuk admin/operator, bisa difilter peran & kata kunci */
    public function daftar_pengguna($peran = NULL, $q = NULL, $limit = NULL)
    {
        $this->db->select(self::KOLOM_PUBLIK)->from($this->table);
        if (in_array($peran, self::PERAN, TRUE)) $this->db->where('role', $peran);
        if ($q)
        {
            $this->db->group_start()->like('name', $q)->or_like('email', $q)->or_like('phone', $q)->group_end();
        }
        if ($limit) $this->db->limit($limit);
        return $this->db->order_by('created_at', 'DESC')->get()->result();
    }

    public function hitung_per_peran()
    {
        $hasil = array_fill_keys(self::PERAN, 0);
        foreach ($this->db->select('role, COUNT(*) AS n')->group_by('role')->get($this->table)->result() as $r)
        {
            $hasil[$r->role] = (int) $r->n;
        }
        return $hasil;
    }

    public function daftar_sejak($datetime)
    {
        return $this->db->where('created_at >=', $datetime)->count_all_results($this->table);
    }

    public function ubah_peran($id, $peran)
    {
        return $this->ubah_profil($id, array('role' => $peran));
    }

    public function hapus($id)
    {
        return $this->db->delete($this->table, array('id_user' => (int) $id));
    }

    public function email_dipakai_lain($email, $kecuali_id)
    {
        return $this->db->where('email', strtolower($email))->where('id_user !=', (int) $kecuali_id)
            ->count_all_results($this->table) > 0;
    }
}

models/Login_attempt_model.php

<?php
defined('BASEPATH') OR exit('No direct script access allowed');

/**
 * Catatan percobaan login.
 * Dipakai untuk (1) membatasi percobaan gagal dan (2) log aktivitas di dashboard admin.
 */
class Login_attempt_model extends CI_Model
{
    private $table = 'login_attempts';

    public function catat($email, $ip, $berhasil, $user_agent)
    {
        $this->db->insert($this->table, array(
            'email'      => strtolower(trim($email)),
            'ip_address' => $ip,
            'berhasil'   => $berhasil ? 1 : 0,
            'user_agent' => mb_substr((string) $user_agent, 0, 255),
            'created_at' => date('Y-m-d H:i:s'),
        ));
    }

    /**
     * Waktu terkunci berakhir (timestamp) bila email+IP sedang dikunci, atau NULL.
     * Aturan: >= $batas kali gagal dalam $jendela menit terakhir (setelah login berhasil
     * yang terakhir) mengunci login selama $kunci menit sejak kegagalan terakhir.
     */
    public function terkunci_sampai($email, $ip, $batas, $jendela, $kunci)
    {
        $email = strtolower(trim($email));
        $sejak = date('Y-m-d H:i:s', time() - $jendela * 60);

        $sukses_terakhir = $this->db->select_max('created_at')
            ->where(array('email' => $email, 'ip_address' => $ip, 'berhasil' => 1))
            ->get($this->table)->row()->created_at;
        if ($sukses_terakhir && $sukses_terakhir > $sejak) $sejak = $sukses_terakhir;

        $gagal = $this->db->select('COUNT(*) AS n, MAX(created_at) AS terakhir', FALSE)
            ->where(array('email' => $email, 'ip_address' => $ip, 'berhasil' => 0))
            ->where('created_at >', $sejak)
            ->get($this->table)->row();

        if ((int) $gagal->n < $batas) return NULL;
        $buka = strtotime($gagal->terakhir) + $kunci * 60;
        return $buka > time() ? $buka : NULL;
    }

    public function sisa_percobaan($email, $ip, $batas, $jendela)
    {
        $n = $this->db->where(array('email' => strtolower(trim($email)), 'ip_address' => $ip, 'berhasil' => 0))
            ->where('created_at >', date('Y-m-d H:i:s', time() - $jendela * 60))
            ->count_all_results($this->table);
        return max(0, $batas - $n);
    }

    public function terbaru($limit = 8)
    {
        return $this->db->select('a.*, u.name, u.role')
            ->from($this->table.' a')
            ->join('users u', 'u.email = a.email', 'left')
            ->order_by('a.id', 'DESC')->limit($limit)->get()->result();
    }

    public function ringkasan_24jam()
    {
        $r = $this->db->select('COALESCE(SUM(berhasil = 1), 0) AS sukses, COALESCE(SUM(berhasil = 0), 0) AS gagal', FALSE)
            ->where('created_at >=', date('Y-m-d H:i:s', time() - 86400))
            ->get($this->table)->row();
        return (object) array('sukses' => (int) $r->sukses, 'gagal' => (int) $r->gagal);
    }
}

models/Remember_token_model.php

<?php
defined('BASEPATH') OR exit('No direct script access allowed');

/**
 * Token "Ingat saya" dengan pola selector + validator.
 *  - selector  : acak, disimpan apa adanya, dipakai untuk mencari baris token
 *  - validator : acak, hanya hash SHA-256-nya yang disimpan
 * Jika database bocor, isi tabel ini tidak bisa dipakai untuk membuat cookie yang sah.
 */
class Remember_token_model extends CI_Model
{
    private $table = 'remember_tokens';

    /** @return string nilai cookie "selector:validator" */
    public function buat($id_user, $hari)
    {
        $selector  = bin2hex(random_bytes(12));   // 24 karakter
        $validator = bin2hex(random_bytes(32));   // 64 karakter
        $this->db->insert($this->table, array(
            'id_user'        => (int) $id_user,
            'selector'       => $selector,
            'validator_hash' => hash('sha256', $validator),
            'expires_at'     => date('Y-m-d H:i:s', time() + $hari * 86400),
            'created_at'     => date('Y-m-d H:i:s'),
        ));
        return $selector.':'.$validator;
    }

    public function cari_selector($selector)
    {
        return $this->db->get_where($this->table, array('selector' => $selector))->row();
    }

    public function hapus($id)
    {
        $this->db->delete($this->table, array('id' => (int) $id));
    }

    public function hapus_selector($selector)
    {
        $this->db->delete($this->table, array('selector' => $selector));
    }

    /** Cabut semua perangkat yang diingat milik seorang pengguna */
    public function hapus_milik($id_user)
    {
        $this->db->delete($this->table, array('id_user' => (int) $id_user));
        return $this->db->affected_rows();
    }

    public function jumlah_aktif($id_user)
    {
        return $this->db->where('id_user', (int) $id_user)->where('expires_at >', date('Y-m-d H:i:s'))
            ->count_all_results($this->table);
    }

    public function bersihkan_kedaluwarsa()
    {
        $this->db->delete($this->table, array('expires_at <' => date('Y-m-d H:i:s')));
    }
}

Langkah 4. Library Autentikasi & Controller Auth

Session hanya menyimpan id_user; data pengguna dan perannya dibaca ulang dari database setiap request, sehingga perubahan peran oleh admin langsung berlaku.

libraries/Autentikasi.php

<?php
defined('BASEPATH') OR exit('No direct script access allowed');

/**
 * Library autentikasi ShopEase.
 * Session hanya menyimpan id_user; data pengguna (termasuk peran) dibaca ulang
 * dari database setiap request, sehingga perubahan peran oleh admin atau akun
 * yang dihapus langsung berlaku tanpa menunggu pengguna logout.
 */
class Autentikasi
{
    const COOKIE = 'shopease_ingat';

    /** hash palsu agar waktu proses email tak terdaftar sama dengan password salah */
    const HASH_PEMBANDING = '$2y$12$nBPu69f4NoWHzA0bQJRrmuOcWJxw5PUR8RQuUefrXyevXIpCg8AIW';

    /** @var CI_Controller */
    protected $CI;
    protected $user = FALSE;   // FALSE = belum dibaca, NULL = tamu

    public function __construct()
    {
        $this->CI =& get_instance();
        $this->CI->config->load('akses');
        $this->CI->load->model(array('user_model', 'remember_token_model', 'login_attempt_model'));
        $this->CI->load->helper('cookie');
        // masuk otomatis dari cookie "Ingat saya" bila sesi sudah habis
        $this->_masuk_dari_cookie();
    }

    /* ---------------- status ---------------- */

    public function cek()
    {
        return $this->user() !== NULL;
    }

    /** @return object|null pengguna yang sedang login (tanpa password) */
    public function user()
    {
        if ($this->user === FALSE)
        {
            $id = $this->CI->session->userdata('id_user');
            $u = $id ? $this->CI->user_model->cari($id) : NULL;
            if ($id && ! $u)
            {
                // akun sudah dihapus admin: bersihkan sesi
                $this->CI->session->unset_userdata(array('id_user', 'masuk_pada'));
            }
            if ($u) unset($u->password);
            $this->user = $u ?: NULL;
        }
        return $this->user;
    }

    public function peran()
    {
        return $this->cek() ? $this->user()->role : NULL;
    }

    public function beranda_peran($peran = NULL)
    {
        $map = $this->CI->config->item('beranda_peran');
        $peran = $peran ?: $this->peran();
        return isset($map[$peran]) ? $map[$peran] : '';
    }

    /* ---------------- login / logout ---------------- */

    /**
     * Periksa email & password.
     * @return object|false user bila cocok
     */
    public function verifikasi($email, $password)
    {
        $user = $this->CI->user_model->cari_by_email($email);
        // password_verify tetap dijalankan walau email tidak ada, agar lama proses sama
        $cocok = password_verify((string) $password, $user ? $user->password : self::HASH_PEMBANDING);
        return ($user && $cocok) ? $user : FALSE;
    }

    public function masuk($user, $ingat = FALSE)
    {
        // ID sesi diganti setelah login untuk mencegah session fixation
        $this->CI->session->sess_regenerate(TRUE);
        $this->CI->session->set_userdata(array('id_user' => (int) $user->id_user, 'masuk_pada' => time()));
        $this->CI->user_model->catat_login($user->id_user);
        $this->user = FALSE;

        if ($ingat)
        {
            $hari = (int) $this->CI->config->item('ingat_saya_hari');
            $this->_pasang_cookie($this->CI->remember_token_model->buat($user->id_user, $hari), $hari * 86400);
        }
    }

    public function keluar()
    {
        $selector = $this->_selector_cookie();
        if ($selector) $this->CI->remember_token_model->hapus_selector($selector);
        delete_cookie(self::COOKIE);
        $this->CI->session->unset_userdata(array('id_user', 'masuk_pada'));
        $this->CI->session->sess_regenerate(TRUE);
        $this->user = NULL;
    }

    /** Lupakan semua perangkat (hapus semua token Ingat saya milik pengguna) */
    public function lupakan_semua_perangkat($id_user)
    {
        delete_cookie(self::COOKIE);
        return $this->CI->remember_token_model->hapus_milik($id_user);
    }

    public function diingat()
    {
        return $this->_selector_cookie() !== NULL;
    }

    /* ---------------- pembatasan percobaan ---------------- */

    public function terkunci_sampai($email)
    {
        $c = $this->CI->config;
        return $this->CI->login_attempt_model->terkunci_sampai($email, $this->CI->input->ip_address(),
            $c->item('login_batas_gagal'), $c->item('login_jendela_menit'), $c->item('login_kunci_menit'));
    }

    public function catat_percobaan($email, $berhasil)
    {
        $this->CI->login_attempt_model->catat($email, $this->CI->input->ip_address(), $berhasil, $this->CI->input->user_agent());
    }

    public function sisa_percobaan($email)
    {
        return $this->CI->login_attempt_model->sisa_percobaan($email, $this->CI->input->ip_address(),
            $this->CI->config->item('login_batas_gagal'), $this->CI->config->item('login_jendela_menit'));
    }

    /* ---------------- internal: cookie Ingat saya ---------------- */

    private function _masuk_dari_cookie()
    {
        if ($this->CI->session->userdata('id_user')) return;

        $nilai = (string) get_cookie(self::COOKIE);
        if ( ! preg_match('/^([a-f0-9]{24}):([a-f0-9]{64})$/', $nilai, $m)) return;

        $token = $this->CI->remember_token_model->cari_selector($m[1]);
        $sah = $token && $token->expires_at > date('Y-m-d H:i:s')
            && hash_equals($token->validator_hash, hash('sha256', $m[2]));

        if ( ! $sah)
        {
            // selector cocok tetapi validator salah = kemungkinan cookie dicuri: cabut semua token pengguna itu
            if ($token) $this->CI->remember_token_model->hapus_milik($token->id_user);
            delete_cookie(self::COOKIE);
            return;
        }

        $user = $this->CI->user_model->cari($token->id_user);
        if ( ! $user) return;

        // token sekali pakai: hapus yang lama, masuk() akan membuat token baru (rotasi)
        $this->CI->remember_token_model->hapus($token->id);
        $this->masuk($user, TRUE);
        $this->CI->session->set_flashdata('info', 'Selamat datang kembali, '.$user->name.'. Kamu masuk otomatis lewat "Ingat saya".');
    }

    private function _selector_cookie()
    {
        $nilai = (string) get_cookie(self::COOKIE);
        return preg_match('/^([a-f0-9]{24}):/', $nilai, $m) ? $m[1] : NULL;
    }

    private function _pasang_cookie($nilai, $detik)
    {
        $this->CI->input->set_cookie(array(
            'name'     => self::COOKIE,
            'value'    => $nilai,
            'expire'   => $detik,
            'httponly' => TRUE,
        ));
    }
}

controllers/Auth.php — register, login, logout

<?php
defined('BASEPATH') OR exit('No direct script access allowed');

/**
 * Registrasi, login, dan logout.
 *   /register  GET form, POST simpan akun baru (peran selalu customer)
 *   /login     GET form, POST periksa email & password
 *   /logout    POST saja (memakai token CSRF)
 * Pengguna yang sudah login tidak bisa membuka /login dan /register (diatur hook Penjaga_akses).
 */
class Auth extends MY_Controller
{
    public function register()
    {
        if ($this->input->method() === 'post')
        {
            $this->form_validation->set_rules('name', 'Nama', 'trim|required|min_length[3]|max_length[100]');
            $this->form_validation->set_rules('email', 'Email', 'trim|required|valid_email|max_length[100]|is_unique[users.email]',
                array('is_unique' => 'Email ini sudah terdaftar. Silakan masuk.'));
            // aturan berbentuk array karena regex mengandung "|" (string aturan CI3 dipecah dengan "|")
            $this->form_validation->set_rules('phone', 'Nomor HP', array('trim', 'regex_match[/^(\+62|62|0)8[0-9]{7,11}$/]'),
                array('regex_match' => 'Nomor HP harus diawali 08 atau +628, 10–14 digit.'));
            $this->form_validation->set_rules('address', 'Alamat', 'trim|max_length[300]');
            $this->form_validation->set_rules('password', 'Password', 'required|min_length[8]|max_length[72]|callback__password_kuat');
            $this->form_validation->set_rules('password_confirm', 'Ulangi password', 'required|matches[password]',
                array('matches' => 'Ulangi password tidak sama.'));

            if ($this->form_validation->run())
            {
                $id = $this->user_model->daftar(array(
                    'name'     => $this->input->post('name', TRUE),
                    'email'    => $this->input->post('email', TRUE),
                    'phone'    => (string) $this->input->post('phone', TRUE),
                    'address'  => (string) $this->input->post('address', TRUE),
                    'password' => $this->input->post('password'),
                ));
                // akun baru langsung masuk, tidak perlu login ulang
                $this->auth->masuk($this->user_model->cari($id));
                $this->session->set_flashdata('sukses', 'Akun berhasil dibuat. Selamat datang di ShopEase!');
                redirect('akun');
            }
        }

        $this->render('auth/register', array('title' => 'Daftar — ShopEase'));
    }

    public function login()
    {
        $email = '';
        $galat = NULL;

        if ($this->input->method() === 'post')
        {
            $email    = strtolower(trim((string) $this->input->post('email', TRUE)));
            $password = (string) $this->input->post('password');

            $this->form_validation->set_rules('email', 'Email', 'trim|required|valid_email');
            $this->form_validation->set_rules('password', 'Password', 'required');

            if ($this->form_validation->run())
            {
                $kunci = $this->auth->terkunci_sampai($email);
                if ($kunci)
                {
                    // percobaan saat terkunci tidak dicatat agar tidak memperpanjang kuncian
                    $galat = 'Terlalu banyak percobaan gagal untuk email ini. Coba lagi pukul '.date('H:i', $kunci).' ('.max(1, ceil(($kunci - time()) / 60)).' menit lagi).';
                }
                elseif ($user = $this->auth->verifikasi($email, $password))
                {
                    $this->auth->catat_percobaan($email, TRUE);
                    $this->auth->masuk($user, (bool) $this->input->post('ingat'));

                    $tujuan = $this->session->userdata('tujuan_login');
                    $this->session->unset_userdata('tujuan_login');
                    $this->session->set_flashdata('sukses', 'Halo, '.$user->name.'. Kamu berhasil masuk.');
                    redirect($tujuan ?: $this->auth->beranda_peran($user->role));
                }
                else
                {
                    $this->auth->catat_percobaan($email, FALSE);
                    $sisa = $this->auth->sisa_percobaan($email);
                    // pesan sama untuk email tak terdaftar & password salah
                    $galat = 'Email atau password salah.'.($sisa > 0 && $sisa <= 3 ? ' Sisa '.$sisa.' percobaan sebelum dikunci sementara.' : '');
                    if ($sisa === 0) $galat = 'Email atau password salah. Login untuk email ini dikunci '.$this->config->item('login_kunci_menit').' menit.';
                }
            }
        }

        $this->render('auth/login', array(
            'title' => 'Masuk — ShopEase',
            'email' => $email ?: (string) $this->input->get('email', TRUE),
            'galat' => $galat,
        ));
    }

    public function logout()
    {
        if ($this->input->method() !== 'post')
        {
            show_error('Logout harus lewat tombol Keluar.', 405);
        }
        $this->auth->keluar();
        $this->session->set_flashdata('sukses', 'Kamu sudah keluar. Sampai jumpa lagi.');
        redirect('login');
    }

    /** Password wajib mengandung huruf dan angka */
    public function _password_kuat($pw)
    {
        if ( ! preg_match('/[A-Za-z]/', $pw) || ! preg_match('/[0-9]/', $pw))
        {
            $this->form_validation->set_message('_password_kuat', 'Password harus berisi huruf dan angka.');
            return FALSE;
        }
        return TRUE;
    }
}

Catatan: di CodeIgniter 3, string aturan validasi dipecah dengan tanda |, sehingga regex nomor HP (\+62|62|0) ikut terpotong. Solusinya, aturan ditulis sebagai array. Bug ini sempat muncul saat pengujian lalu diperbaiki.

hooks/Penjaga_akses.php

<?php
defined('BASEPATH') OR exit('No direct script access allowed');

/**
 * Hook penjaga akses (pengganti Filter CI4 di CodeIgniter 3).
 * Dijalankan pada titik post_controller_constructor, yaitu setelah controller
 * dibuat dan sebelum method-nya dipanggil, berdasarkan peta config/akses.php.
 */
class Penjaga_akses
{
    public function periksa()
    {
        $CI =& get_instance();
        $segmen = (string) $CI->uri->segment(1);

        // 1) halaman khusus tamu: yang sudah login dialihkan ke beranda perannya
        if (in_array($segmen, $CI->config->item('khusus_tamu'), TRUE) && $CI->auth->cek())
        {
            redirect($CI->auth->beranda_peran());
        }

        $aturan = $CI->config->item('akses');
        if ( ! isset($aturan[$segmen]))
        {
            return; // halaman publik
        }

        // 2) wajib login
        if ( ! $CI->auth->cek())
        {
            $tujuan = uri_string().($CI->input->server('QUERY_STRING') ? '?'.$CI->input->server('QUERY_STRING') : '');
            $CI->session->set_userdata('tujuan_login', $tujuan);
            $CI->session->set_flashdata('info', 'Masuk dulu untuk membuka halaman itu.');
            redirect('login');
        }

        // 3) wajib peran tertentu
        $izin = $aturan[$segmen];
        if (is_array($izin) && ! in_array($CI->auth->peran(), $izin, TRUE))
        {
            $this->_tolak($CI, $izin);
        }
    }

    /** Tampilkan halaman 403 lalu hentikan request */
    private function _tolak($CI, array $izin)
    {
        $CI->output->set_status_header(403);
        $data = array(
            'title'   => 'Akses ditolak — ShopEase',
            'izin'    => $izin,
            'halaman' => uri_string(),
        );
        $data['content'] = $CI->load->view('halaman/ditolak', $data, TRUE);
        $CI->load->view('layouts/main', $data);
        $CI->output->_display();
        exit;
    }
}

    {

        {
            $this->session->set_flashdata('galat', 'Data peran tidak valid.');
        }
        elseif ((int) $u->id_user === (int) $this->auth->user()->id_user)
        {
            // mencegah admin terakhir mengunci dirinya sendiri dari panel admin
            $this->session->set_flashdata('galat', 'Kamu tidak bisa mengubah peran akunmu sendiri.');
        }
        else

            $this->session->set_flashdata('sukses', 'Peran '.$u->name.' diubah menjadi '.$baru.'. Berlaku di request berikutnya tanpa perlu login ulang.');

    }

    public function hapus($id = NULL)
    {
        $this->_wajib_post();
        $u = $this->user_model->cari($id);
        if ( ! $u)
        {
            $this->session->set_flashdata('galat', 'Pengguna tidak ditemukan.');
        }
        elseif ((int) $u->id_user === (int) $this->auth->user()->id_user)
        {
            $this->session->set_flashdata('galat', 'Kamu tidak bisa menghapus akunmu sendiri.');
        }
        else
        {
            $this->user_model->hapus($u->id_user);   // token Ingat saya ikut terhapus (ON DELETE CASCADE)

    private function _kembali_query()
    {
        $q = (string) $this->input->post('kembali');
        return $q !== '' && $q[0] === '?' ? $q : '';
    }

    private function _wajib_post()
    {
        if ($this->input->method() !== 'post') show_error('Metode tidak diizinkan.', 405);
    }
}

<?php
defined('BASEPATH') OR exit('No direct script access allowed');

/**
 * Halaman akun untuk semua peran yang sudah login (dijaga hook: 'akun' => 'login').
 *   /akun                 profil + peta akses
 *   /akun/simpan          (POST) ubah nama, HP, alamat

 *   /akun/lupakan         (POST) cabut semua perangkat "Ingat saya"

class Akun extends MY_Controller
{
    public function index()
    {
        $this->config->load('akses');
        $this->render('akun/index', array(

            'u'         => $this->auth->user(),
            'perangkat' => $this->remember_token_model->jumlah_aktif($this->auth->user()->id_user),

        ));
    }

    public function simpan()
    {
        $this->_wajib_post();
        $this->form_validation->set_rules('name', 'Nama', 'trim|required|min_length[3]|max_length[100]');
        $this->form_validation->set_rules('phone', 'Nomor HP', array('trim', 'regex_match[/^(\+62|62|0)8[0-9]{7,11}$/]'),
            array('regex_match' => 'Nomor HP harus diawali 08 atau +628, 10–14 digit.'));
        $this->form_validation->set_rules('address', 'Alamat', 'trim|max_length[300]');

        if ( ! $this->form_validation->run())
        {
            return $this->index();
        }

        $phone = (string) $this->input->post('phone', TRUE);
        $address = (string) $this->input->post('address', TRUE);
        $this->user_model->ubah_profil($this->auth->user()->id_user, array(
            'name'    => $this->input->post('name', TRUE),
            'phone'   => $phone !== '' ? $phone : NULL,
            'address' => $address !== '' ? $address : NULL,
        ));
        $this->session->set_flashdata('sukses', 'Profil disimpan.');
        redirect('akun');
    }

    public function password()
    {
        $this->_wajib_post();
        $this->form_validation->set_rules('password_lama', 'Password lama', 'required|callback__cek_lama');
        $this->form_validation->set_rules('password_baru', 'Password baru', 'required|min_length[8]|max_length[72]|callback__beda_dan_kuat');
        $this->form_validation->set_rules('password_ulang', 'Ulangi password baru', 'required|matches[password_baru]',
            array('matches' => 'Ulangi password baru tidak sama.'));

        if ( ! $this->form_validation->run())
        {
            return $this->index();
        }

        $id = $this->auth->user()->id_user;
        $this->user_model->ganti_password($id, $this->input->post('password_baru'));
        // perangkat lain yang diingat ikut dicabut setelah password diganti
        $dicabut = $this->auth->lupakan_semua_perangkat($id);
        $this->session->sess_regenerate(TRUE);
        $this->session->set_flashdata('sukses', 'Password diganti.'.($dicabut ? ' '.$dicabut.' perangkat yang diingat sudah dikeluarkan.' : ''));
        redirect('akun');
    }

    public function lupakan()
    {
        $this->_wajib_post();
        $n = $this->auth->lupakan_semua_perangkat($this->auth->user()->id_user);
        $this->session->set_flashdata('sukses', $n ? $n.' perangkat tidak lagi diingat.' : 'Tidak ada perangkat yang diingat.');
        redirect('akun');
    }

    public function _cek_lama($pw)
    {
        $u = $this->user_model->cari($this->auth->user()->id_user);
        if ( ! password_verify((string) $pw, $u->password))
        {
            $this->form_validation->set_message('_cek_lama', 'Password lama salah.');
            return FALSE;
        }
        return TRUE;
    }

    public function _beda_dan_kuat($pw)
    {
        if ($pw === $this->input->post('password_lama'))
        {
            $this->form_validation->set_message('_beda_dan_kuat', 'Password baru harus berbeda dari password lama.');
            return FALSE;
        }
        if ( ! preg_match('/[A-Za-z]/', $pw) || ! preg_match('/[0-9]/', $pw))
        {
            $this->form_validation->set_message('_beda_dan_kuat', 'Password harus berisi huruf dan angka.');
            return FALSE;
        }
        return TRUE;
    }

    private function _wajib_post()
    {
        if ($this->input->method() !== 'post') redirect('akun');
    }
}

Hasil Pengujian

Pengujian dijalankan otomatis dengan Playwright di browser Edge. 23 dari 23 pemeriksaan lulus, antara lain:

  • POST /logout tanpa token CSRF ditolak 403.
  • Registrasi dengan email terdaftar atau password tanpa angka ditolak dengan pesan per kolom; registrasi valid langsung masuk ke /akun.
  • Customer membuka /admin dan /operator mendapat 403; yang sudah login tidak bisa membuka /login.
  • 5 kali password salah mengunci login, password benar tetap ditolak selama terkunci, email lain tidak ikut terkunci.
  • Tamu yang membuka /admin/pengguna dikembalikan ke halaman itu setelah login sebagai admin.
  • Admin mengubah peran Dewi menjadi operator; Dewi diarahkan ke /operator dan ditolak di /admin.
  • "Ingat saya": setelah sesi dihapus pengguna masuk otomatis, cookie dirotasi, dan cookie lama ditolak.
  • Ganti password berhasil dan perangkat yang diingat dikeluarkan.

Kesimpulan

Sistem autentikasi ShopEase menunjukkan bahwa CodeIgniter 3 tetap bisa menerapkan pola yang di CodeIgniter 4 dikerjakan oleh Filter, yaitu dengan hook dan peta akses di file config. Password aman karena di-hash dan diverifikasi dengan password_verify(), sesi dilindungi dengan pergantian ID setelah login dan cookie httponly, dan semua aksi yang mengubah data memakai POST + CSRF. Tabel login_attempts dan remember_tokens membuat batas percobaan login dan fitur "Ingat saya" lebih aman serta bisa diaudit.
