Tugas 3 PBKK — UI Registrasi Mahasiswa (WPF .NET)

📂 Source code lengkap: github.com/miaikoo/2026-framework-based-programming

Pada tugas ini dibuat aplikasi desktop sederhana untuk registrasi mahasiswa menggunakan WPF (Windows Presentation Foundation) di .NET 8. Tampilan disusun dengan XAML, sedangkan logikanya ditulis dalam C# code-behind. Langkah instalasi .NET SDK, VS Code, dan C# Dev Kit sama seperti Tugas 1. Catatan: WPF hanya berjalan di Windows.

Fitur

  • Formulir: NIM, Nama, Email, Program Studi (ComboBox), Jenis Kelamin (RadioButton), Tanggal Lahir (DatePicker), Alamat, dan checkbox persetujuan.
  • Validasi: semua kolom wajib, NIM angka 5–12 digit, NIM tidak boleh ganda, format email, tanggal lahir tidak boleh di masa depan, checkbox wajib dicentang.
  • Tabel (DataGrid) mahasiswa terdaftar yang otomatis ter-update beserta jumlahnya.
  • Tombol Reset untuk mengosongkan form dan Hapus Data Terpilih dengan dialog konfirmasi.

1. Buat Proyek WPF

Buka terminal VS Code dengan Ctrl+`, lalu jalankan:

dotnet new wpf -n RegistrasiMahasiswa
cd RegistrasiMahasiswa
code .

Template wpf otomatis membuat App.xaml, MainWindow.xaml, dan file .cs-nya.

Mahasiswa.cs — class data

namespace RegistrasiMahasiswa
{
    // Cetakan data satu mahasiswa yang mendaftar
    public class Mahasiswa
    {
        public string NIM { get; set; }
        public string Nama { get; set; }
        public string Email { get; set; }
        public string Prodi { get; set; }
        public string JenisKelamin { get; set; }
        public DateTime TanggalLahir { get; set; }
        public string Alamat { get; set; }

        // Dipakai DataGrid untuk menampilkan tanggal dengan format rapi
        public string TanggalLahirTeks => TanggalLahir.ToString("dd/MM/yyyy");
    }
}

MainWindow.xaml.cs — logika

using System.Collections.ObjectModel;
using System.Text.RegularExpressions;
using System.Windows;
using System.Windows.Controls;
using System.Windows.Media;

namespace RegistrasiMahasiswa
{
    public partial class MainWindow : Window
    {
        // ObservableCollection: DataGrid otomatis ter-update saat data ditambah/dihapus
        private readonly ObservableCollection<Mahasiswa> daftarMahasiswa = new ObservableCollection<Mahasiswa>();

        public MainWindow()
        {
            InitializeComponent();
            dgMahasiswa.ItemsSource = daftarMahasiswa;
        }

        private void BtnDaftar_Click(object sender, RoutedEventArgs e)
        {
            string nim = txtNim.Text.Trim();
            string nama = txtNama.Text.Trim();
            string email = txtEmail.Text.Trim();

            // ===== Validasi berurutan; berhenti di kesalahan pertama =====
            if (nim == "" || nama == "" || email == "" || txtAlamat.Text.Trim() == "")
            {
                TampilkanPesan("Semua kolom wajib diisi!", true);
                return;
            }
            if (!Regex.IsMatch(nim, @"^\d{5,12}$"))
            {
                TampilkanPesan("NIM harus berupa angka 5–12 digit.", true);
                return;
            }
            if (daftarMahasiswa.Any(m => m.NIM == nim))
            {
                TampilkanPesan("NIM " + nim + " sudah terdaftar.", true);
                return;
            }
            if (!Regex.IsMatch(email, @"^[^@\s]+@[^@\s]+\.[^@\s]+$"))
            {
                TampilkanPesan("Format email tidak valid.", true);
                return;
            }
            if (cmbProdi.SelectedItem == null)
            {
                TampilkanPesan("Pilih program studi.", true);
                return;
            }
            if (rbLaki.IsChecked != true && rbPerempuan.IsChecked != true)
            {
                TampilkanPesan("Pilih jenis kelamin.", true);
                return;
            }
            if (dpTanggalLahir.SelectedDate == null || dpTanggalLahir.SelectedDate > DateTime.Today)
            {
                TampilkanPesan("Isi tanggal lahir dengan benar.", true);
                return;
            }
            if (chkSetuju.IsChecked != true)
            {
                TampilkanPesan("Centang pernyataan persetujuan terlebih dahulu.", true);
                return;
            }

            // ===== Semua valid -> simpan =====
            daftarMahasiswa.Add(new Mahasiswa
            {
                NIM = nim,
                Nama = nama,
                Email = email,
                Prodi = ((ComboBoxItem)cmbProdi.SelectedItem).Content.ToString(),
                JenisKelamin = rbLaki.IsChecked == true ? "Laki-laki" : "Perempuan",
                TanggalLahir = dpTanggalLahir.SelectedDate.Value,
                Alamat = txtAlamat.Text.Trim()
            });

            PerbaruiJumlah();
            KosongkanForm();
            TampilkanPesan("✔ " + nama + " berhasil didaftarkan!", false);
        }

        private void BtnReset_Click(object sender, RoutedEventArgs e)
        {
            KosongkanForm();
            lblPesan.Text = "";
        }

        private void BtnHapus_Click(object sender, RoutedEventArgs e)
        {
            if (dgMahasiswa.SelectedItem is not Mahasiswa terpilih)
            {
                MessageBox.Show("Pilih data di tabel terlebih dahulu.", "Hapus Data",
                                MessageBoxButton.OK, MessageBoxImage.Information);
                return;
            }

            var jawab = MessageBox.Show("Hapus data " + terpilih.Nama + "?", "Konfirmasi",
                                        MessageBoxButton.YesNo, MessageBoxImage.Question);
            if (jawab == MessageBoxResult.Yes)
            {
                daftarMahasiswa.Remove(terpilih);
                PerbaruiJumlah();
            }
        }

        private void KosongkanForm()
        {
            txtNim.Clear();
            txtNama.Clear();
            txtEmail.Clear();
            txtAlamat.Clear();
            cmbProdi.SelectedIndex = -1;
            rbLaki.IsChecked = false;
            rbPerempuan.IsChecked = false;
            dpTanggalLahir.SelectedDate = null;
            chkSetuju.IsChecked = false;
            txtNim.Focus();
        }

        private void PerbaruiJumlah()
        {
            lblJumlah.Text = "Mahasiswa Terdaftar (" + daftarMahasiswa.Count + ")";
        }

        private void TampilkanPesan(string pesan, bool error)
        {
            lblPesan.Text = pesan;
            lblPesan.Foreground = new SolidColorBrush(error ? Color.FromRgb(0xDC, 0x26, 0x26)
                                                            : Color.FromRgb(0x16, 0xA3, 0x4A));
        }
    }
}

Penjelasan Kode

  • XAML vs code-behind — MainWindow.xaml hanya berisi tampilan, sedangkan MainWindow.xaml.cs berisi perilaku. Keduanya terhubung lewat x:Class dan x:Name (misal x:Name="txtNim" bisa dipakai sebagai variabel txtNim di C#).
  • Layout Grid — jendela dibagi menjadi baris header dan isi; bagian isi dibagi dua kolom (form 380px di kiri, tabel mengisi sisa * di kanan). StackPanel menyusun input secara vertikal.
  • App.xaml Resources — warna dan Style didefinisikan sekali lalu dipakai ulang dengan {StaticResource ...}, mirip CSS di web.
  • Click="BtnDaftar_Click" — menghubungkan tombol ke method event handler di code-behind.
  • Validasi berurutan — setiap pengecekan memakai if (...) { TampilkanPesan(...); return; } (guard clause). Regex mengecek NIM (^\d{5,12}$) dan email; Any() dari LINQ mengecek NIM ganda.
  • ObservableCollection<Mahasiswa> — mirip List, tetapi memberi tahu UI setiap ada perubahan. Karena dijadikan ItemsSource DataGrid, tabel otomatis ter-update tanpa refresh manual.
  • Data binding — kolom DataGrid memakai Binding="{Binding Nama}" sehingga isi sel diambil langsung dari properti objek Mahasiswa.
  • MessageBox YesNo — dialog konfirmasi sebelum menghapus agar data tidak terhapus tanpa sengaja.
  • TanggalLahirTeks — properti hanya-baca (=>) yang mengubah DateTime menjadi teks dd/MM/yyyy.
